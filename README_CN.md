# Bookshelf 虚拟书架

## 2026-09-15 改版

- 书架首页直接混排“分类封面入口 + 未分类单书”，不再显示“未分类书籍”中转入口。
- 通过 Simple UI 的外部 Quick Action 接口注册独立“书架”底栏候选项，不替换原“书籍”按钮，也不自动改动底栏设置。
- 统一封面、标题和作者占位高度，并修复封面图片覆盖右侧、底部及圆角边框的问题；旧缩略图会通过新版缓存键自动失效。
- 分类页新增返回书架入口；Simple UI 通过公开的 Bar Injection 接口识别书架页，底栏不会再误亮“书籍库”。
- 分类选择默认先编辑草稿，点击“完成”才一次保存；“取消”撤销勾选和本次临时新建的分类。设置中可改为点选后立即加入或移出。
- 从书架打开书籍后，正常退出阅读器会返回原分类和原页；返回信息只保留在当前 KOReader 进程内。
- 阅读返回改为 FileManager 首个 UI tick 恢复，并在书架 Grid 注入前预先激活 `bookshelf_open`，避免先闪原书籍库或误亮相邻底栏标签。
- 分类封面顶部增加三层由窄到宽的透视书页线；三层之间及最下层与封面之间采用相同间距。分类封面本体与普通书籍使用完全相同的尺寸计算，书名与作者之间的空白也已压缩。
- “书架”现已进入 Simple UI 的快速操作图标选择页，可像内置“书库”一样单独换图标；插件禁用时会清理运行时目录项。
- 阅读进度使用紧凑的上平下尖圆弧书签角标，可在布局设置中选择白、灰、黑三种底色；浅色底自动使用黑字，黑底使用白字。角标宽度取封面宽度的 `5/24`，矩形高为角标宽度的 `3/5`、三角形高为 `3/10`；中心位于封面宽度 `4/5` 处，顶部超出角标总高度的 `1/4`。文字按原字号约 `80%` 绘制并在整个角标内居中，`1%` 到 `100%` 的外框尺寸和位置完全一致。
- 书架标题栏的 `+` 旁新增排序按钮，可按名称、书籍文件修改时间或 KOReader 最后阅读时间排序；另保留“手动顺序”，切换排序不会重写分类中的保存顺序。
- 修复进度角标底色只更新设置选中状态、书架实际角标仍沿用旧颜色的问题；角标现在在绘制时读取白/灰/黑设置，并在切换后刷新被主菜单覆盖的书架层。

## 2026-09-14 修复

- 修复点击“未分类书籍”时因文件名解析函数所属模块错误而返回原界面的问题。
- 修复从书架点击未分类或分类内书籍时，界面关闭顺序可能与 Simple UI/KOReader 阅读器启动冲突的问题。

Bookshelf 是面向 KOReader 2026.07.1 的独立封面书架插件。分类只保存电子书的绝对路径和顺序；打开书籍时仍调用 KOReader 打开原文件，因此阅读进度、历史、书签、批注和元数据继续使用原来的 `.sdr` 数据。

## 安装

1. 解压安装包，把完整的 `bookshelf.koplugin` 目录复制到 `koreader/plugins/`。
2. 完全退出并重新启动 KOReader。
3. 在主菜单打开“书架 → 打开书架”。“启动时打开书架”默认关闭，不会抢占 Simple UI 首页。
4. 同时启用 Simple UI 时，可在它的底栏标签设置中选择“书架”；在“快速操作图标”中可单独修改其图标。插件只提供候选项，不会自行替换或重排现有按钮。

## 使用

- 书架首页右上角 `+`：创建分类；旁边的排序按钮可选择手动顺序、名称升序、文件时间最新优先或最后阅读时间最新优先。长按分类可重命名、删除或调整顺序；删除分类只删除分类记录。
- 在 KOReader 文件管理器中长按电子书，选择“加入书架”，可勾选多个分类；默认点击“完成”后才统一保存，“取消”不产生改动。同一本书可属于多个分类。
- 进入分类后，轻点书籍打开原文件；长按可加入其他分类、移出当前分类或调整分类内顺序。
- 首页先显示用户分类，随后直接显示每一本未分类书籍。只要一本书属于至少一个分类，它就不会再单独出现在首页。
- 主菜单“书架 → 布局与文字设置”可选择分类操作方式和进度角标底色，并分别调整封面百分比、竖/横屏列数、比例、裁剪、间距、圆角、每页行数，以及书名、作者、分类名称的字体、字号、行数、对齐和省略方式。

## 数据、缓存与恢复

- 私有数据：`koreader/settings/bookshelf.lua`；KOReader 写入时使用临时文件、同步、备份和替换机制，旧备份为 `bookshelf.lua.old`。
- 私有缩略图：`koreader/cache/bookshelf/`；可以随时从菜单清除，原书和阅读数据不会受影响。
- 文件移动或重命名后，旧路径会显示为失效记录，新路径会进入“未分类书籍”。可把新路径重新加入分类，再移除或清理旧记录。
- 若存储暂时不可用，插件保留分类记录；清理功能会在书库根目录不可用时拒绝执行，并保守地跳过根目录之外的失效路径。
- 设置文件损坏时，KOReader 会读取 `bookshelf.lua.old`。仍无法恢复时，退出 KOReader，把两个文件移走即可得到空书架；电子书和 `.sdr` 数据无需恢复。
- 禁用或删除插件后，它会移除自己的长按入口并关闭书架窗口；没有修改 Simple UI、CoverBrowser、文件管理器或阅读数据。

## 已知限制

- 首次看到一本从未提取过封面的书时，需要在前台逐本生成当前页缩略图；后续翻页直接使用缓存。超大书库首次扫描目录会有短暂停顿，但不会一次载入全库高清封面。
- 移动或重命名目前不会按文件内容自动猜测新路径，以免把同名书误配；需要手动重新加入分类。
- 当前交付已用 KOReader 2026.07.1 源码做接口核对、Lua 5.1 语法检查和宿主模型测试，尚未在用户的实体 Kindle 上完成触控与墨水屏视觉验收。
