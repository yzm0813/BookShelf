# Bookshelf 虚拟书架

Bookshelf 是面向 KOReader 2026.07.1 的独立封面书架插件。分类只保存电子书的绝对路径和顺序；打开书籍时仍调用 KOReader 打开原文件，因此阅读进度、历史、书签、批注和元数据继续使用原来的 `.sdr` 数据。

## 安装

1. 解压安装包，把完整的 `bookshelf.koplugin` 目录复制到 `koreader/plugins/`。
2. 完全退出并重新启动 KOReader。
3. 在主菜单打开“书架 → 打开书架”。“启动时打开书架”默认关闭，不会抢占 Simple UI 首页。

## 使用

- 书架首页左上角 `+`：创建分类。长按分类：重命名、删除或调整顺序。删除分类只删除分类记录。
- 在 KOReader 文件管理器中长按电子书，选择“加入书架”，可勾选多个分类。同一本书可属于多个分类。
- 进入分类后，轻点书籍打开原文件；长按可加入其他分类、移出当前分类或调整分类内顺序。
- 首页只显示用户分类和“未分类书籍”。只要一本书属于至少一个分类，它就不会再单独出现在首页。
- 主菜单“书架 → 布局与文字设置”可分别调整封面百分比、竖/横屏列数、比例、裁剪、间距、圆角、每页行数，以及书名、作者、分类名称的字体、字号、行数、对齐和省略方式。

## 数据、缓存与恢复

- 私有数据：`koreader/settings/bookshelf.lua`；KOReader 写入时使用临时文件、同步、备份和替换机制，旧备份为 `bookshelf.lua.old`。
- 私有缩略图：`koreader/cache/bookshelf/`；可以随时从菜单清除，原书和阅读数据不会受影响。
- 文件移动或重命名后，旧路径会显示为失效记录，新路径会进入“未分类书籍”。可把新路径重新加入分类，再移除或清理旧记录。
- 若存储暂时不可用，插件保留分类记录；清理功能会在书库根目录不可用时拒绝执行，并保守地跳过根目录之外的失效路径。
- 设置文件损坏时，KOReader 会读取 `bookshelf.lua.old`。仍无法恢复时，退出 KOReader，把两个文件移走即可得到空书架；电子书和 `.sdr` 数据无需恢复。
- 禁用或删除插件后，它会移除自己的长按入口并关闭书架窗口；没有修改 Simple UI、CoverBrowser、文件管理器或阅读数据。

## 已知限制

- 首次看到一本从未提取过封面的书时，需要在前台逐本生成当前页缩略图；后续翻页直接使用缓存。超大书库首次扫描目录会有短暂停顿，但不会一次载入全库高清封面。
- 移动或重命名目前不会按文件内容自动猜测新路径，以免把同名书误配；需要手动重新加入分类。
- 当前交付已用 KOReader 2026.07.1 源码做接口核对、Lua 5.1 语法检查和宿主模型测试，尚未在用户的实体 Kindle 上完成触控与墨水屏视觉验收。

## 文件结构

```text
bookshelf.koplugin/
├── _meta.lua                  插件元数据
├── main.lua                   生命周期、菜单和分类/书籍操作
├── bookshelf_grid.lua         独立封面网格及横竖屏排版
├── bookshelf_store.lua        私有数据、稳定 ID、排序与原子持久化
├── bookshelf_scanner.lua      受支持书籍扫描与未分类过滤
├── bookshelf_covercache.lua   参数化缩略图缓存、裁剪与圆角
├── bookshelf_i18n.lua         中文界面映射及默认 gettext
├── CONFLICT_AUDIT_CN.md       CoverBrowser/Simple UI 冲突审查
├── TEST_REPORT_CN.md          测试范围和结果
└── tests/                     可重复运行的数据模型测试
```
